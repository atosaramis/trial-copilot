Trial Copilot protocol vs registry check

Does a trial's protocol describe the same study as its ClinicalTrials.gov record? This tool reads the protocol, compares six design fields with the public registry record, and shows every difference with the protocol page, the exact quote and how the record changed later.

A registry-accuracy and protocol quality check, not medical advice. It does not predict whether a trial will succeed or fail. It uses only public study-level documents: no patient data, and no clinical, diagnostic or treatment advice.

What this is

Sponsors register each clinical trial on ClinicalTrials.gov, and they also write a protocol: the detailed plan. The two should agree. When they don't, for example on how many sites, how many patients or how many treatment groups, either the record is out of date or the plan has changed, and someone should check.

Trial Copilot does that check. A Meta Muse model reads the protocol PDF and pulls out the design fields with page citations. Code compares them with the trial's January 2017 registry record. For each difference, a Muse investigation agent re-reads the protocol, explains what it found and quotes the page; code then confirms every quote appears word for word on that page.

How we checked it

  • Findings come with evidence. Every difference shows the protocol page and quote, and the registry value in Jan 2017, 2020 and 2023. Links go to the official protocol PDF on ClinicalTrials.gov at the cited page.
  • Quotes are verified by code, not by the model. A quote the agent offers is kept only if it is found word for word on the page it names. A quote that isn't found is dropped and shown as dropped.
  • Blind second-model grading. We picked 45 deliberately tricky differences from other trials (not the demos). An independent AI model from another provider labelled each one blind, without seeing the agent's answer. Where it and the Muse agent disagreed, two further models, including Muse Wonder reading the full protocol, re-read the documents to break the tie.
  • Result: about 76% agreement. On those 45 tricky rows the Muse agent's call matched the final label about 3 times in 4. The misses were mostly numbers that were not the actual plan, such as "up to N" limits, how many patients must finish, or dose levels counted as arms. We fixed the extraction for these and re-checked.
  • AI-adjudicated, not human ground truth. These labels come from AI models checking each other against the documents, not from an expert panel. A difference here is a prompt to open two public documents, not a finding of fault.

Data and credits

Registry data: U.S. National Library of Medicine, ClinicalTrials.gov, via the CTTI AACT database (snapshots of Jan 5, 2017; Jan 1, 2020; Jan 2, 2023). Protocol PDFs belong to their sponsors; they are linked on ClinicalTrials.gov, never copied here. Only short quotes are shown.

Built with Meta Muse models: Muse Spark 1.3 (protocol reading and the investigation agent) and Muse Wonder 1.0 (full-protocol review). Built for the Meta AI Developer Hackathon, 2026.
