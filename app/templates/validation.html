Did reading the protocol help? No detectable gain

pre-registered, tuning set

On the {{ t.n }} tuning trials (which were part of the registry baseline's original training data, so A is in-sample there), the pre-registered selection (cross-validated log loss) chose no protocol feature. So the app's score (B) is the registry baseline recalibrated, and on the held-out set B and A rank trials identically: the B − A AUC difference is 0 by construction, a tie.

Why the models never output the risk number

prior research, before the hackathon

In an Oct 13 study of 7 low-cost non-Meta models on 15,634 registry records, none beat a 13-field registry baseline at flagging the trials later stopped for poor enrollment, so here models read and search, and code computes every number.

Full write-ups: docs/backtest-tuning.md and docs/backtest-heldout.md. The held-out set was scored once, after the rule was locked (addendum sha256 {{ h.addendum_sha256[:8] }}…{{ h.addendum_sha256[-4:] }}). The 5 demo trials are in the held-out set.
