Primary-outcome triage which trials' main question changed after they started, and which of those a person should look at

A trial's primary outcome is the main question it commits to answer before it starts. If it changes later, readers can't tell whether the answer was chosen after the data came in, unless someone compares the protocol, the registry history, the amendments and the analysis plan. That takes hours per trial. Trial Copilot narrows {{ '{:,}'.format(o.funnel[0].n) }} trials to a short list a person can check in an afternoon, with every claim tied to a dated page.

How far to trust this

  • The model's first call is not the answer. Of the {{ o.review.checked }} flagged trials checked against amendments and analysis plans so far, {{ o.review.explained }} were explained by the trial's own documents. That is why the output is a review queue, not a list of findings.
  • AI-checked, not expert-verified. The amendment and analysis-plan review behind the shortlist was done by an AI agent reading the documents; no clinical expert has checked it yet. {{ o.funnel[4].n - o.review.checked }} flagged trials have not yet been checked against their amendments and analysis plans.
  • Not a prevalence estimate. The trials are those that posted a protocol and were running in Jan 2017; we don't know how many changes the filters missed.
  • Dates are windows. Registry changes are dated by the yearly snapshots they fall between (Jan 2017, 2018, 2020, 2023), not by the day. The record history on ClinicalTrials.gov gives exact dates; it has no official API, so we did not collect it automatically.
  • Quotes are checked by code. A quote is shown only if code finds it word for word on the page it cites. 69 of 73 quotes from the protocol read passed; the rest were dropped.
  • Prior work. The COMPare project and earlier studies of outcome reporting compared trial publications with protocols by hand. This triage aims to make that first pass cheaper, not to replace the reading.
  • Not medical advice and not a regulatory finding. A difference between public documents is a prompt to look, not a finding of fault. Corrections are welcome as issues on the GitHub repository.
