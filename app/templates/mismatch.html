Caveats

  • Most of the agreement gain is bookkeeping. The fixes mark doubtful readings ("up to N", other counts, multi-part designs) so the history no longer pretends to settle them. That shrank the settled set from {{ v2.settled }} to {{ v3.settled }}. The agent itself did not get better.
  • The registry history is not ground truth. A later change can mean the record caught up, or that the plan changed. "Never changed" means the record kept its value, not that the protocol was right.
  • Tuned and scored on the same trials. The rules were set by looking at these {{ v3.trials }} tuning trials, so these numbers flatter them. No held-out test of the mismatch check has been run yet.
  • One saved model run. Verdicts come from one run at minimal reasoning. They are a reading aid; a person should open the page and check, especially cards marked "Check this".
  • Small numbers. {{ v3.settled }} settled cases. Remaining disagreements: {{ v3.disagreements|join(', ') }}.
